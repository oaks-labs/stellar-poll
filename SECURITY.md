# Security Policy

## Supported Versions

| Version | Supported | Notes |
|---|---|---|
| `0.2.x` / `HEAD` | Yes | Active development on Stellar Protocol 21+ |
| `< 0.2.0` | No | Prototype learning-challenge versions |

---

## Reporting a Vulnerability

If you discover a security vulnerability or exploit in the StellarPoll smart contracts or web application, please **do not open a public GitHub issue**.

Please report security issues responsibly by contacting the maintainer via:
- **Email**: `kayode.olaleye.dev@gmail.com`
- **Subject**: `[SECURITY VULNERABILITY] StellarPoll - <brief summary>`

### What to include in your report:
1. Detailed description of the vulnerability.
2. Step-by-step reproduction instructions or a test scenario.
3. Potential impact on voter privacy, transaction integrity, or contract storage.
4. Suggested remediation if known.

We will acknowledge receipt of your report within 48 hours and work with you to test and deploy a fix before public disclosure.
